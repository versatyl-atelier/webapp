# Versatyl

## Getting Started

### Setup (first time)

- See [System Requirements](docs/sys-reqs.md)
- `git clone <repo>`
- `cd <repo>`
- `cp .env.example .env`
- `npm install`

### For the rest

- Have a look at your options by running:

```bash
npm run
```
