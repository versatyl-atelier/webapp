# Copy-writing conventions

- Everything user-facing is in French (`fr-CA`), including error messages
- Domain concepts keep their French name in the code too (models, routes, functions, e.g. `jobines`, `lanceur`), so the code and the UI call them the same thing
- Everything else in the code and the docs is in English
- Some older code translates domain names to English. Don't copy that, and don't rename it unless asked
