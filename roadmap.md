# Roadmap

Looking into the future will allow us to make sure we start right away accumulating the data and planning for these future features architecturally

## Phase 1

Web App Versatyl et son premier outils Punch.

### Application Web Versatyl

- Site web regroupant tous les outils
- Sécurité de base
- Architecture robuste
- Styles uniformes
- Centralisation des données
- Données en temps réel
- Format téléphone pour toutes les pages
- Outils de recherche important!
- Recherche avec Whisprflow

### Versatyl Punch

- Application de punch avec API Trello et interface gestionnaire
- Outil déjà existant, épouvé
- Redesign pour le web
- Pas de login par utilisateur (login général seulement)
- Rendre plus évident les overrides de punch qui ne sont actuellement visible que dans l'aperçu mais pas dans le rapport avancé
- Le design général est à conserver

### Lanceur de date

- Outil de planification d’échéancier
- Outil déjà existant, embryonnaire, à peaufiner
- Redesign pour le web
- Liens
- Notifications
- Calculs
- Ne sert qu'à obtenir une date de dispo pour le future éloigné, pas le bon outils pour le future proche
- Il sera utile de revoir le lanceur de dates
